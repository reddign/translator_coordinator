Epic 3: Translator Finder

US-13	As a user, I want to indicate whether I am willing to provide translation assistance so that people searching for translators know whether they may contact me.
US-14	As an event organizer, I want to search for translators by language so that I can find someone who can assist at an event.
US-15	As an event organizer, I want translator search results to show language proficiency so that I can identify users who meet my needs.
US-16	As a user searching for a translator, I want to view a potential translator's profile so that I can determine whether they are appropriate for my needs.
US-17	As a translator, I want to control whether I appear in translator search results so that I can decide when I am available to help.	
US-18	As an event organizer, I want to filter translator results by language and proficiency level so that I can narrow my search.
US-19	As an event organizer, I want to search for translators associated with a particular country or region so that I can find someone with relevant cultural knowledge.
