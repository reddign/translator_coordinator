User Story:
As a group creator, I want to associate my group with a country, region, or language so that users can discover relevant groups.

Acceptance Criteria:

The group creator can associate their group with a country from the db
The group creator can associate their group with a region from the db
The group creator can associate their group with a language from the db
These tags should be displayed with the group description
These tags should be linked to the filter/search system
Multiple tags of the same catagory can be added
The same tag cannot be added twice
