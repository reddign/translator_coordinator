US-01 *	As a new user, I want to create an account so that I can participate in the World Connections community.

US-02 *	As a registered user, I want to log in and log out securely so that my profile information is protected.

US-03	As a user, I want to create and edit my profile so that other users can learn about me.

US-04	As a user, I want to identify my country of origin so that others can find people connected to that country.

US-05	As a user, I want to associate myself with additional countries so that I can indicate countries where I have lived, traveled, studied, or have other connections.

US-06	As a user, I want to associate myself with regions of the world so that other users can discover people with regional experience or interests.

US-07	As a user, I want to view another user's public profile so that I can learn about their countries, regions, languages, and interests.
