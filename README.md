# translator_coordinator
CS341-Fall 2026 Project - World Connections

World Connections is a web-based application designed to connect people who are interested in learning about countries, regions, and languages around the world. The system will allow users to create profiles identifying their countries of origin, associated countries and regions, spoken languages, and language proficiency.

The system will also provide two primary community features:

Translator Finder — allows users or event organizers to search for users who speak particular languages and may be available to provide translation services.
Interest and Language Groups — allows users to create and join groups focused on learning about countries, regions, or practicing specific languages.

The application will be developed as a collaborative Software Engineering project using a LAMP (Linux, Apache, MySQL/MariaDB, PHP) technology stack. A RESTful API will provide programmatic access to application data and functionality.
